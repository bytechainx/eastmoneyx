# eastmoneyx 能力标准

**crate**：`eastmoneyx` v0.1.1 | **source_id**：`eastmoney` | **角色**：东方财富宏观观测的离线源事实库

> `production_decision = NO-GO`。清单 COMPLETE ≠ ship；authorization ≠ Production Ready。
> 本文件是安装/使用/AIDD 三张表的判定基准；`tests/sdd_spec.rs` 的 `// SPEC-MAP:` 与之逐节 1:1。

---

## 1. 范围标准（仅脱敏宏观观测）

- 当前合同只承认 `kind=observation` + `product=macro`：`validate_observation_scope` 放行该组合，
  其余产品类别一律拒绝为路由他处（`RoutedElsewhere`）。
- **必须拒绝**：行情（`Quote`）/ 汇率（`Forex`）/ 搜索（`Search`）/ 日历（`Calendar`）。
- 清单 §1.3 的 5 类规划类型齐备：`MoneySupply` / `InterbankRate` / `AggregateFinancing` /
  `NorthboundFlow` / `OmoOperation`（`SERIES_KINDS` 长度为 5）。
- 规划端点**不等于**访问合同：本库**不含任何端点字面量**，也不登记规划端点的标识符。

## 2. 值对象与期间标准

- `Date { year, month, day }`：月 1–12；日按月份与闰年规则校验；年份须为 4 位形态（1000–9999）。
- `Date::parse` 只接受严格 ISO `YYYY-MM-DD`（月/日两位补零）；拒绝 `2026-2-3`、`2026/08/15`、
  带时间部分者与非法日历（如 `2026-02-29`）。
- `Period::parse` 覆盖四种形态：`YYYY-MM-DD` → `Day`、`YYYY-MM` → `Month`、`YYYY-Qn` → `Quarter`
  （`n` ∈ 1–4）、`YYYY` → `Year`；其余形态拒绝。
- `EastMoneyCode`（源侧码）非空、无前后空白、无控制字符、不超过 64 字符；**取值域由源决定**，
  本层 MUST NOT 虚构取值全集（清单未钉死 `op_type` 之类的取值）。
- 取值模型为 `EastMoneyValue::{Present(f64), Missing(EastMoneyMissingReason)}`：缺失**必须以具名原因**
  表达（`SourceBlank` / `NotPublishedYet` / `NotApplicable`），MUST NOT 静默转 0；
  `Present` 不得为 `NaN` 或无穷。
- **单位保留源侧**：`Unit` ∈ {`Percent`, `BasisPoint`, `HundredMillionYuan`, `Yuan`, `Undeclared`}；
  换算归下游 Normalize，本层不做。观测级 `unit` 适用于该类型的量值列，`change_bp` 恒为基点、
  `*_yoy` 恒为百分比（清单语义钉死，故不另设列）。
- `revision`（修订标识）：本域**无官方 vintage 面**，恒为 `None`，MUST NOT 伪造。
- 频率不由列给出，由类型决定：货币供应量与社融为 `Monthly`，同业利率与北向资金为 `Daily`，
  公开市场操作为 `Event`。
- 禁止字段：任何派生指标（净投放 5d / 中美利差 / M2−社融剪刀差 / 资金面松紧度 / 北向动量 /
  流动性综合指数）、任何网络或凭据相关字段。

## 3. 解析标准（CSV）

- 只实现脱敏 **CSV**；入口形态为「`&str` → 值对象集合」，MUST NOT 接受 URL、客户端或凭据参数。
- **JSONP 剥离属授权后的未来任务，当前未实现**：`guard_parse_format(Jsonp)` 返回 `NotApplicable`。
- **表头严格匹配**：列数与列名逐字相等。多一列、少一列、改名或改序一律原子失败
  （MUST NOT 静默忽略未知字段）。已知列名如下。

  | 解析入口 | 表头 |
  | --- | --- |
  | `parse_eastmoney_observations` | `series,period,m0,m1,m2,m0_yoy,m1_yoy,m2_yoy,unit` |
  | `parse_eastmoney_interbank_rates` | `period,series,rate,change_bp,unit` |
  | `parse_eastmoney_aggregate_financing` | `series,period,increment,stock,yoy,unit` |
  | `parse_eastmoney_northbound_flows` | `date,sh_net,sz_net,total_net,balance,unit` |
  | `parse_eastmoney_omo_operations` | `date,op_type,term_days,amount,rate,net_injection,unit` |

- 同业利率序列令牌为 `SHIBOR_ON` / `DR007` / `LPR_1Y`，**大小写敏感**；未知令牌拒绝。
- 表头与身份字段保留原始空白，不静默修剪。同业利率期间必须为严格日度日期。
- 期间年份统一为 1000–9999；货币供应量校验复验公开期间分量。
- 数值列：空单元格 → `Missing(SourceBlank)`；非数值或非有限值 → 拒绝。
- 单位列令牌：`%` / `bp` / `亿元` / `元`；空 → `Undeclared`；未知令牌拒绝（不得静默降级）。
- `term_days` 必须是无符号整数；缺列或非整数拒绝。
- **重复身份：本层选择「拒绝」**（不静默去重），返回 `SemanticallyRejected`。身份定义：
  货币供应量 `series + period`；同业利率 `series + period`；社融 `series + period`；
  北向资金 `date`；公开市场操作 `date + op_type`。
- 空输入与仅换行输入视为缺少表头而拒绝。
- 输入**首部**的 UTF-8 BOM 由 CSV 读取器剥离（不改变列名，也不静默丢列）；列名匹配仍逐字严格。
- 错误消息不回显原始行内容、响应正文或凭据。

## 4. 授权与执行纪律标准

- 授权日期必须为有效日历日期。范围令牌以空白、分号或逗号分隔；`kind=observation` 和 `product=macro` 必须精确出现一次，同名重复或冲突键拒绝。
- **授权现状为 `unknown`**：无 Owner 签核文件，全部端点许可 UNKNOWN。`authorize_eastmoney_access`
  fail-closed：证据缺失、空、签署者不明、覆盖范围未显式声明 `kind=observation` 与 `product=macro`、
  或已过期 → 一律 `Denied`；MUST NOT 默认放行。
- `current_eastmoney_authorization()` 恒为 `Denied`（只读判定，不改写清单登记值）。
- `live_proxy_access = denied_pending_owner_reruling`；`proxy_support_target = required`
  ——**技术接线不构成联网授权**。
- `guard_live_execution` 对七类通道**一律拒绝**：联网、User-Agent 伪装、代理轮换、
  Cookie/Challenge、验证码绕过、无头浏览器、JSONP 假宣称。任何代码或配置 MUST NOT 以代理池绕过。

## 5. publication 语义标准

- `eastmoney_publication_semantics()` 恒返回 `(TimePrecision::Date, AvailabilityEvidence::Inferred,
  PitEligibility::NotEligible)`；`is_formal_pit_eligible()` 恒为 `false`。
- MUST NOT 补造 `00:00 UTC` 之类时刻把 `Date` 伪装成 `Instant`；MUST NOT 静默升格为正式 PIT。
- 评审证据层为推断层：本域未接入官方 vintage 面或经签批的发布日历。
